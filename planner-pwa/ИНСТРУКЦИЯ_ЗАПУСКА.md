# FOCUS — инструкция по запуску (для получателя архива)

Персональный PWA-планнер: задачи, привычки, проекты, финансовые цели. Данные хранятся в браузере на вашем устройстве.

---

## Что нужно установить один раз

**Node.js** (версия 18 или новее): https://nodejs.org/

Проверка в терминале:

```text
node -v
```

Должна появиться строка вида `v20.x.x` или `v22.x.x`.

Другие программы и `npm install` **не нужны** — в проекте нет внешних зависимостей.

---

## Быстрый старт (Windows)

1. Распакуйте архив в любую папку, например `C:\Projects\FOCUS-planner`.
2. Откройте **PowerShell** или **Командную строку**.
3. Перейдите в папку с проектом:

```powershell
cd C:\Projects\FOCUS-planner
```

(Замените путь на свой.)

4. Запустите сервер:

```powershell
node server.js
```

или:

```powershell
npm start
```

5. В браузере откройте: **http://localhost:4173**

6. Остановка сервера: в том же окне терминала нажмите `Ctrl+C`.

---

## macOS / Linux

```bash
cd /путь/к/папке/planner-pwa
node server.js
```

Браузер: **http://localhost:4173**

Другой порт (если 4173 занят):

```bash
PORT=8080 node server.js
```

## Установка на телефон (PWA)

1. Разместите проект на хостинге с **публичным HTTPS** (например [Netlify Drop](https://app.netlify.com/drop) — перетащить папку `planner-pwa`).
2. Откройте выданный URL на телефоне.
3. **Android (Chrome):** меню → «Установить приложение» / «Добавить на главный экран».
4. **iPhone (Safari):** «Поделиться» → «На экран „Домой“».

Локальный `localhost` с другого телефона **не откроется** — нужен общий URL в интернете.

## Важно про данные

- Всё сохраняется в **localStorage** браузера на этом устройстве.
- Очистка данных сайта в браузере **удалит** задачи и привычки.
- Синхронизация между телефоном и ПК в этой версии **не настроена** (планируется через облако).

## Частые проблемы

| Проблема | Решение |
|----------|---------|
| `'node' is not recognized` | Установите Node.js и перезапустите терминал |
| Страница не открывается | Убедитесь, что `node server.js` запущен и нет ошибок в терминале |
| Порт занят | `set PORT=8080` (Windows) или `PORT=8080` (Mac/Linux), затем снова `node server.js` |
| Старый интерфейс после правок | Обновите страницу с полным сбросом кэша: `Ctrl+Shift+R` |
