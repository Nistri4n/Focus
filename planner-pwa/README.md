# FOCUS — персональный PWA-планнер

Локальное приложение для задач, привычек, проектов и финансовых целей (тёмный интерфейс, работает в браузере и как PWA).

**Подробная инструкция для нового пользователя:** [ИНСТРУКЦИЯ_ЗАПУСКА.md](./ИНСТРУКЦИЯ_ЗАПУСКА.md)

## Запуск за 30 секунд

1. Установите [Node.js](https://nodejs.org/) (LTS).
2. В терминале откройте эту папку и выполните:

```powershell
node server.js
```

3. Откройте в браузере: **http://localhost:4173**

Альтернатива: `npm start`

Зависимости через `npm install` **не требуются**.

## Возможности

- адаптивный интерфейс для телефона и компьютера;
- тип дня: рабочий / выходной / отпуск / больничный;
- разовые и регулярные задачи (регулярные привязаны к типу дня);
- канбан задач, проекты с этапами и прогрессом;
- месячный трекер привычек и SVG-графики;
- финансовые цели без обязательного дедлайна;
- локальный помощник (анализ плана; Gemini — следующий этап);
- сохранение в `localStorage`, офлайн после первого визита.

## Деплой

Статический хостинг: загрузите содержимое папки на Netlify/Vercel/GitHub Pages. Для корректной работы service worker нужен **HTTPS**.
